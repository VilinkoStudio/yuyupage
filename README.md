## 功能

- 天气显示
- 基本搜索
- WebDAV 数据同步（支持坚果云）
- Bing 壁纸
- 网站网址联想
- 快捷翻译
- 快捷计算（支持+ - * /）
- 搜索联想
- 多语言支持
- 日期快速计算（输入 Totime + 年月日 获取目标日期到今天的剩余天数。例如 `Totime2026-06-15` ）
